Agent Runtime & Registry
Agent를 코드 없이 조립하고, 등록하고, 배포한다
▾

AgentCore Runtime은 Agent 코드를 컨테이너로 실행하는 서버리스 환경이다. Agent 개발자는 인프라를 관리하지 않고 Agent 로직에만 집중한다.

Agent Card는 각 Agent의 역할, 권한, 사용 가능한 Tool, Delegation 대상을 선언적으로 정의한다. Platform이 이 Card를 기반으로 라우팅과 권한 제어를 수행한다.

A2A Delegation
Agent끼리 협업한다 — 사람이 팀에게 업무를 위임하듯
▾

Scoped Delegation은 Agent가 사전 정의된 대상에게만 업무를 위임하는 방식이다. Supervisor처럼 범용 라우팅이 아니라, 각 Agent의 Config에 명시된 대상만 호출할 수 있어 보안과 예측 가능성을 확보한다.

Agent Card 기반 라우팅으로 Supervisor가 사용자 의도를 분류하고, 적합한 Domain Agent에게 위임한다.

Tool Gateway (MCP)
여러 Account의 AWS 서비스를 Agent가 안전하게 사용한다
▾

MCP (Model Context Protocol) 기반으로 각 Gateway가 AWS 서비스 Tool을 표준화된 인터페이스로 제공한다. Agent는 Gateway만 알면 되고, 뒤의 AWS 서비스 구현은 몰라도 된다.

Cross-Account IAM으로 각 Account의 리소스에 안전하게 접근하며, Context Boundary로 Agent가 허용된 Tool만 호출하도록 범위를 제한한다.

LLM Gateway
모델을 교체/분산/제어한다
▾

LiteLLM 스타일 라우팅으로 여러 LLM 제공자(Bedrock, OpenAI, Anthropic 등)를 단일 엔드포인트로 통합한다. Agent는 모델 제공자를 의식하지 않고 API를 호출한다.

모델별 비용/속도 트레이드오프 설정, Fallback (1순위 모델 실패 시 대체 모델 자동 전환), Rate Limiting (팀/Agent별 호출량 제한)을 Platform 레벨에서 중앙 관리한다.

Observability
Agent가 무엇을 하고 있는지 실시간으로 본다
▾

AgentCore Observability는 OpenTelemetry 기반으로 Agent 실행을 span 단위로 추적한다. 각 Tool 호출, A2A Delegation, LLM 추론 과정이 trace로 기록되어 병목과 오류를 정확히 파악할 수 있다.

CloudWatch 연동으로 메트릭, 로그, 트레이스를 통합 관리하며, Agent 실행 이력과 비용을 대시보드에서 확인한다.

Harness
Agent를 개발하고 테스트하고 배포하는 파이프라인
▾

Dev → Test → Deploy 생명주기를 표준화한 Agent 개발 파이프라인이다. 개발자가 Agent Config를 정의하면 자동으로 Quality Gate(린트, 테스트, 보안 검사)를 통과한 뒤 AgentCore에 배포된다.

CI/CD 통합으로 Agent 변경사항을 코드 리뷰 → 자동 테스트 → 프로덕션 배포 순서로 관리한다. 롤백과 버전 관리가 가능하다.
